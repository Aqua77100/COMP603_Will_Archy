HOW TO PLAY 'SYNC':

1. Once you clone the repository, run the project and the game will start.
2. Read through the dialogue presented on screen and press continue to go to the next.
3. You'll ocasionally be presented with choices on how to progress the story. Evaluate the choices and press the correct one to progress the story.
    Pressing the incorrect option will result in death and you can either return to the title screen and restart the game, or quit the game.
4.  During the security scene, you'll have to click and drag each wire from the left side of the window the the corresponding port on the right side.
    Please note; there's a hint as to which wires connect to which ports in the background image.
5. After this, you'll receive a jumbeled password that you have to rearrange to reveal the password to get into the factory
  You'll receive two hints at the password terminal after a number of incorrect guesses. If you are still unable to get it, the password is 'knockknock'.
6. In the final scene, you must play hangman with the antagonist. You have 11 guesses to get the word before you die. Additionally, if you guess a wrong letter, you have a
   chance of taking damage from Sync.
7. Once complete, you can chose to abandon or save Sync. From there, the game is complete.
8. You'll return to the title screen where you can either quit the game or view the leaderboard where your score will appear.
